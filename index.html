Resumen

Idea central y alcance

Objetivo

Centralizar la gestión de trabajo de TI personal y de un equipo pequeño, manteniendo control de dependencias, prioridades, entregables y riesgo.

Incluido en MVP

  • Workspaces, proyectos y plantillas
  • Tablero Kanban, backlog y sprints
  • Campos personalizados y comentarios
  • Roles, MFA y auditoría

Fuera de alcance

  • Tiempo real colaborativo
  • Integraciones externas
  • IA y facturación
  • Multi-organización

Flujo del producto

Cómo opera el MVP en la práctica

01

Configura tu espacio

Crea workspaces, define roles por proyecto y elige una plantilla: Kanban, Scrum o PMI.

02

Gestiona el trabajo

Asigna épicas, historias, tareas, riesgos y dependencias con control de estados y prioridad.

03

Audita y protege

Registra cambios, activa MFA, valida adjuntos y mantiene trazabilidad de accesos sensibles.

Stack recomendado

Arquitectura tecnológica

Frontend

Next.js + TypeScript

React con App Router, Tailwind, shadcn/ui y dnd-kit para dashboards y tableros.

Backend

NestJS

API REST modular con OpenAPI, validación y capa de negocio clara y extensible.

Datos

PostgreSQL + Prisma

Relacional, transaccional y seguro, con JSONB para campos personalizables.

Jobs

pg-boss

Recordatorios, exportación y procesamiento asíncrono sobre el mismo motor de datos.

Auth

Sesiones + TOTP

Autenticación segura por proyecto, roles y auditoría con atención a datos sensibles.

Infra

Docker + Caddy

Despliegue local portable, con HTTPS local y preparación para migración futura.
